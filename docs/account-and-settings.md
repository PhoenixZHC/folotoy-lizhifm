# 设备账号、设置与缓存

更新时间：2026-11-12（Asia/Shanghai），Ubuntu 开发电脑。当前正式1.0电量版源码与BIN已发布main，下载入口为[README](../README.md)。历史全片刷写清空旧设置后，电量版仅更新应用并验证启动联网；不再以待配网描述最新状态。当前绑定未重新确认，登录/播放仍沿用此前历史证据；实机覆盖边界见交付验证记录。

## 账号绑定

首页进入设置 → 荔枝账号 → 扫码绑定/切换账号，用荔枝 App 扫设备二维码并确认。二维码由荔枝官方创建，过期后短按确定刷新，长按确定返回。只有读取到真实、完整的字符串用户 ID，且独立 NVS 写入成功后，界面才返回首页并提示已保存。取消或失败保留原账号。

协议依次为 `growth.lizhi.fm/njQrcode/get`、`/njQrcode/authLoginSuccCallBack`、`nj.lizhi.fm/account/doLoginByQrcode`，随后在 `njnew.lizhi.fm/user/getCurrentUserInfo` 取得 ID/昵称。所有请求校验证书、拒绝自动重定向，正文上限 16KiB。一次性 token 和 Cookie 仅在本次确认流程 RAM 中使用；不存 Flash，不输出到日志。解析限制深度、长度、重复字段、UTF-8 和嵌入 NUL，ID 不经 double 转换。

当前普通关注接口只需要已核实的用户 ID，设备保存的是绑定身份，不是手机完整会话，也不恢复手机端收听历史。付费/受限节目未返回音频地址时会提示需要购买或授权；没有付费解锁、令牌导入或代理回退。

退出账号默认选择取消，用户确认后才保存解绑；保留 Wi-Fi。账号切换/退出清空当前页面和播放选择，新旧关注及最近收听按账号隔离。原先的未绑定本地续听保留，并明确标为“本地”。

## 网络与显示

- 首次没有网络配置时自动扫描；已有配置失败时仍可从设置进入无线网络，选择热点重新输入密码。
- 扫描 2.4GHz，最多读取 24 条原始结果，去重显示 12 个热点。短按上下选字符、确定输入，长按上下换字符组；长按确定进入连接/删除/显隐操作。密码不写源码或日志。
- 成功连接、完成校时后才写入独立 `lizhi_wifi`；旧 `netease_wifi` 仅作只读兼容。保存失败不提示成功，配置写入过程中不允许取消，避免界面与存储分叉。
- 切换前先保留驱动中的原网络配置；新网络连接失败或任务取消时恢复原配置，下次业务请求连接原网络。恢复配置不等于已经联网；若恢复本身失败则明确提示重新选网。若新网络已经连接但存储失败，保留当次连接并明确提示未保存，重启仍读取原持久配置。
- 已联网后断开，自动重连最多10次且不超过30秒；首次/手动联网仍有20秒超时。音频下载最多10次重试并受30秒无进展窗口限制，以覆盖热点短暂关闭后恢复；仍失败则显示错误，等待用户重试，不无限重连。下载的Range恢复仍校验总长度与资源身份；播放错误后手动重试使用当前帧锚点续播，“从头播放”单独由菜单触发。
- 播放页长按上/下进入音量并增/减5%，音量页短按上下继续调整，短按或长按确定保存并返回实际播放状态；熄屏后首键仅唤醒。
- 离线或播放错误时，底部显示“OK 长按重试”，长按确定重连并从当前进度恢复；短按确定重试仍兼容。正常播放时长按确定打开快捷菜单。用户接受有界自动尝试后手动重试，不要求热点恢复后必须自动续播。
- 亮度 10–100%，音量 0–100%，熄屏可选一直亮屏/30/60/120 秒。首键只唤醒，播放继续。设置有版本、CRC，加载/保存错误明确显示，不自动清空数据。

## 关注和续听存储

`lizhi_settings/config_v1` 保存账号 ID/昵称、绑定代次、音量、亮度、熄屏；`lizhi_library/snapshot_v1` 保存完整关注快照；`lizhi_progress/scoped_v1` 保存一个账号范围内的最近节目和真实帧锚点。原 `latest_v1` 本地记录保持独立。所有新记录均校验版本/长度或结构、账号及 CRC；账号 ID 也包含在续听封套校验中。

关注仍以每次两位的小请求串行读取，完整校验后才整体替换快照；中途失败、重复数据、取消或写入失败不提交半份列表。浏览快照不要求联网，界面注明“已保存的关注”，设置可主动刷新。每屏四位，内存最多 128 位；设备原 NVS 只有 24KiB，实际可写容量还受其他记录影响，超过空间明确报错，不能承诺 128 位一定可持久保存。

自然播完只在下载完整、已有音频输出、无错误且非手动停止时报告一次，待音频任务退出后才自动下一集。手动停止、断网失败、权限错误不会触发跳集。

## 最近播放

首页第二项固定为“最近播放”，进入四行列表，显示最近四集节目名称及“已听分钟:秒 / 总时长”；未知总时长只显示已听位置。选中长名称滚动，确定从该集记录位置续播，下方提示“长按 OK 返回首页”。按集ID去重，继续同一集更新进度并移到首位，第五集淘汰最旧一集；没有记录时显示空状态。保存时机沿用播放每分钟、暂停和停止，尚未产生有效帧锚点的极短播放不写记录；等待新节目启动时不将旧音频锚点误写到新节目。

历史记录使用独立版本/账号/CRC封套，一次NVS提交；读取旧单条记录时不改写，下一次保存才迁移至四条格式，旧键保留。未绑定记录和账号记录分开，校验或保存失败明确提示。仅历史页临时分配完整列表，进入前停止并保存音频、开始续播前释放列表，避免四份记录常驻挤占音频内存。
