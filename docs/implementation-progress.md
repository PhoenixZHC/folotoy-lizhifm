```bash

python3 tools/probe_lizhi.py --author-id '<已核实的博主用户ID>' --page 2 --page-size 8
```

此工具是证据收集工具，非正式荔枝客户端。当前 `code/data/voiceInfo.voiceId` 来自已有接口线索，非已验证的真实节目协议；结构不同会报错并保留原始响应。解析不经过浮点转换，重复 ID 单独报告，空页不宣称博主有效或分页结束。正文上限 16 KiB，单次网络操作超时 20 秒，重定向上限 5 次。不设置未经证据支持的 UA/Referer，不重试 403，也不转代理。

媒体 URL 可能带签名，请仅保存在本机 `.local-backup/` 下的文本文件，不发到聊天、不写进文档、不要把完整 URL 直接放入命令参数：

```bash
python3 tools/probe_lizhi.py --media-url-file .local-backup/media-url.txt
```

媒体探测默认只读首 4096 字节，支持 `--range-start 1048576` 验证非零字节起点，检查 `206` 与 `Content-Range`，不自动请求整集。忽略 Range 返回大正文时会因上限失败。`ID3` 或 MPEG 同步字仅是格式线索，不证明完整 MP3 可解码或 seek 正确；200、416、格式未知、资源验证器及 URL 时效仍需结合真实资源单独验收。

工具退出码 0 只表示当前响应满足探测条件，不表示整批次 B、账号或设备验收通过；失败返回 1。正常取得的原始响应与摘要，以及网络失败摘要，写入 `.local-backup/lizhi-probes/`，每次独立目录，不覆盖旧证据。正文文件/摘要权限 600，单次目录权限 700；媒体摘要只保留主机名，不输出签名路径或查询参数。
