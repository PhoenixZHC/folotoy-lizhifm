# 荔枝播放器使用说明

适用设备：ESP32-C3，8 MiB Flash，无PSRAM。当前交付为正式版1.0；设置与关于页读取固件内嵌版本号。

右上角显示CW2017电量百分比，约每5秒采样更新；读数不可用显示“--%”。采用参考项目的默认电池参数，未做本电芯充放电标定。

## 日常使用

首页包含“我的关注”“最近播放”“设置”。未绑定时第一项为“绑定荔枝账号”。上下短按移动，短按OK选择；列表长按OK返回。熄屏后第一次按键只唤醒，音频继续播放。

“我的关注”读取当前绑定账号的真实关注，每屏四位博主；进入博主后每屏四集节目，移到页面边缘可翻页。选择一集开始收听。选中的长节目名会滚动。

“最近播放”保留最近四集节目和各自已听位置，最近收听在最上方。同一集更新进度并前移，第五集替换最旧的一集。短按OK从对应位置继续，长按OK返回首页。进度在暂停、停止及播放期间每分钟保存；突然断电可能损失最近一分钟。账号记录相互隔离。

## 播放按键

| 操作 | 作用 |
| --- | --- |
| 短按OK | 暂停或继续 |
| 长按上/下约0.6秒 | 进入音量调整并增减5%；进入后松手 |
| 音量页短按上/下 | 继续增减音量 |
| 音量页按OK | 保存，返回真实播放/暂停状态 |
| 播放页短按上/下 | 上一集/下一集；最近四集内未听完节目保留历史位置 |
| 正常播放时长按OK | 快捷菜单：停止返回列表、音量、快退15秒、快进30秒、从头播放 |
| 播放失败时长按OK | 重连并从当前可验证位置重试；短按OK也兼容 |

播放页显示一次博主名、大字节目标题、已听/总时长和音量。超长标题在固定区域滚动，进度位置不移动。菜单定位依靠已验证MP3帧锚点，缺少锚点时明确提示；“从头播放”才主动清除本次续播意图。

正常听完一集后顺序播放下一集；手动停止、权限或网络错误不会误触发自动下一集。收费或未授权节目未提供播放地址时，设备明确提示，不绕过服务端权限。

## 网络与账号

在设置中扫描并选择2.4GHz Wi-Fi。密码页短按上下选择字符、短按OK输入；长按上下切换字符组，长按OK进入连接/删除/显隐/返回操作。成功连接后才保存新配置。

更换热点失败时会恢复原网络设置；长按返回后，再进入节目可尝试连接原网络。若新网络已连接但保存失败，会明确提示，重启后仍使用原来保存的网络。若显示原配置恢复失败，请重新选择网络。

热点暂时关闭时会尝试有界恢复；若显示播放失败，恢复热点后长按OK重试。已观察到部分手机热点恢复后自动扫描仍找不到，手动重试可连接，此行为保留。联网和音频重试均有上限，不无限占用设备。

账号页可切换账号或退出。切换使用荔枝App扫描设备二维码；过期按OK刷新。取消不覆盖原绑定。退出须在设备确认，退出后隐藏原账号关注和历史。二维码、Cookie和短时令牌不持久写入Flash。

## 更新与验收边界

仓库当前正式1.0电量版位于`dist/`。日常更新将应用BIN写入`0x10000`，仅适用于相同分区布局，可保留设置。首次安装将完整8MiB BIN写入`0x0`，会清空账号、Wi-Fi及历史，需要重新配网和扫码。下载及首次操作见[README](../README.md)。本地`release/lizhi-1.0/`为旧交付记录，最新本地包为`release/lizhi-1.0-battery-9eb78d5d/`。

验收证据和限制见同目录的交付验证记录。手机实际长按手感由硬件ADC与按键持续时间共同决定；0.6秒门槛及长短事件路径已核对，自动串口测试不能代替机械按键手感。账号真正退出后重新扫码、另一账号切换未再次操作，避免打断现有账号；其隔离/保存失败路径由主机测试覆盖，原设备扫码绑定已有成功证据。
